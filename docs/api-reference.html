Introduction

All endpoints, with example requests and responses.

Base URL http://localhost:4000
Format JSON request and response bodies
Auth httpOnly cookie, set by Login. Always send credentials: "include" (fetch) or withCredentials: true (axios).
Roles admin, employee
Success response shape
{ "statusCode": 200, "success": true, "message": "...", "data": { ... } }
Error response shape
{ "success": false, "message": "Access token not found" }

Auth

Register, log in and refresh the session.

Register

POST/api/auth/registerPublic
Request
fetch("http://localhost:4000/api/auth/register", {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    name: "Aarav Sharma",
    email: "aarav.sharma@example.com",
    password: "secret123",
    department: "developer"
  })
})
  .then(res => res.json())
  .then(json => console.log(json));
Response · 201
{
  "statusCode": 201,
  "success": true,
  "message": "Employee registered successfully",
  "data": {
    "_id": "6650a1f2c3b4d5e6f7a8b9c0",
    "name": "Aarav Sharma",
    "email": "aarav.sharma@example.com",
    "role": "employee",
    "avatar": "",
    "department": "developer",
    "status": "active",
    "createdAt": "2026-05-14T10:00:00.000Z",
    "updatedAt": "2026-05-14T10:00:00.000Z"
  }
}
